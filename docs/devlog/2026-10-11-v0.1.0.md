# v0.1.0: Foundations

*2026-10-11, Paul Carouge*

Alcove starts as a monorepo with one rule: every client talks to the same small, secure server,
and nothing is built before the contract exists.

**What landed.** A single Go binary built on PocketBase serves the API, realtime and the web app.
`GET /health` advertises the server version and the API range it speaks, so the web and mobile apps
can say "update the app" or "update the server" instead of failing strangely. Design tokens live in
one JSON file and generate both the CSS and the Flutter theme, with contrast checked by tests.
`docker compose up` brings the server and Caddy (automatic HTTPS).

**What went wrong.** The first real look at the web page in a browser showed... nothing. Two Content
Security Policies were enforced together: the server's header blocked the inline script that
SvelteKit's own policy allowed. The fix reads SvelteKit's script hashes at startup and merges them
into a single header, and browser tests now guard against it. The CI was also red from the first
push: a job-level `permissions` block silently removed read access to the private repository.
