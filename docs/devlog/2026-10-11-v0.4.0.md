# v0.4.0: Seeing your files

*2026-10-11, Paul Carouge*

**Selecting and moving.** Checkboxes with shift-click ranges, a toolbar for bulk actions, a "Move
to…" dialog with a folder browser, and drag-to-move onto folders or the breadcrumbs. The dialog is
the keyboard-accessible path; dragging is the shortcut.

**Previews.** Thumbnails in the list, a grid view, and a full-screen viewer for images, text, video,
audio and PDF, with arrow keys to browse. Thumbnails are generated by PocketBase on first request and
cached; originals are never touched.

**Security.** Showing user files in the browser is where self-hosted apps get hurt. Only passive
formats are ever displayed inline, with a sandboxing Content Security Policy. HTML and SVG, which can
run scripts, always download.

**What went wrong.** Screenshots caught what tests did not: selected rows whose checkboxes looked
unchecked (a `preventDefault` undoing the visual toggle), and images overflowing the grid and the
viewer. The tests now assert the checked state too.
