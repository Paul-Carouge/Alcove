# v0.11.1: The photos that were already there

*2026-10-12, Paul Carouge*

Restarting my own development server to try the albums, I noticed something the tests never would: the
photos module only looked at files when they were uploaded or changed. Every test starts from an empty
server and uploads its pictures, so they all passed. But anyone who had put photos in their drive with
v0.9 and then updated would open Photos and find it empty, as if the pictures had vanished.

At start-up, Alcove now looks for image and video files that have no photo record yet and processes them
in the background, two at a time, like new uploads. A test now covers a file that "predates" the module.

The lesson is an old one: test the update, not only the fresh install.
