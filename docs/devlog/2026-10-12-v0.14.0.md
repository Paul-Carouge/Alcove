# v0.14.0: A map that stays at home

*2026-10-12, Paul Carouge*

Phones remember where every picture was taken. This release puts that to use: **Photos → Map** shows your
library on a world map, photos taken close together merge into a single thumbnail with a count, and they
split apart as you zoom in. Click one to open it in the viewer; from any located photo in the timeline,
"Show on map" brings you there.

## The map itself was the hard question

Most web maps load their pictures from a tile server somewhere: every time you pan, your browser tells
that server where you are looking. For a map of *your own photos*, that means telling a stranger where you
went on holiday. And a home server may not even have internet access.

So Alcove ships its own map: the world's countries, coastlines and about 580 cities from Natural Earth, a
public-domain dataset, packed into one file served by your server. It is not a street map, but it needs
nothing and tells nobody anything. A test opens the map and fails if a single request leaves the server.

When detail matters more than that, an administrator can switch on OpenStreetMap tiles on the System page,
with a sentence explaining what it means. Alcove's security policy normally forbids loading images from
other sites; the tile server is added to it only while the switch is on, so even a bug could not quietly
start sending requests elsewhere.

## What went wrong

- **A map without photos.** The end-to-end test opened the map right after uploading and found nothing:
  locations are read when a photo is processed, a moment later. The test now waits, like a person would.
- **Every city at once.** Zoomed out over Europe, a hundred city names piled on top of each other. Labels
  are now placed from the most populous down and skipped when they would overlap.
- **A blank map, then.** That fix asked the map where a city was on screen before the map knew where it
  was looking, which throws. Labels are drawn once the view is set.
- The error shown when a page fails to load said "Could not load this folder" everywhere, including on the
  map. It now says "this page".
