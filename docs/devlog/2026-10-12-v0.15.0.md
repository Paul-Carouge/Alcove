# v0.15.0: Alcove in your pocket

*2026-10-12, Paul Carouge*

With the photo features in place, the next question was what to build first: documents with text
recognition, or the phone app. I chose the app. For a family, the feature that replaces Google Photos or
iCloud is the one that quietly copies every new picture from the phone to the server, and that needs an app.
This release lays the foundation; automatic backup is the next one.

## What the app does now

Until today the app could only check that an address pointed to an Alcove server; its Continue button did
nothing. Now it continues to a sign-in screen that behaves exactly like the web: password, then the
authenticator code (or a recovery code) or the code sent by email, depending on how the account is
protected. The session is kept in the phone's secure storage and refreshed at each start; a token revoked
from elsewhere sends you back to sign-in.

Three tabs follow:

- **Photos**: the timeline, month by month, with video durations and favorites. Swipe through photos full
  screen, pinch to zoom, play videos, mark favorites, read the details.
- **Files**: your folders, folders first, and files that open in the phone's browser.
- **Account**: who you are, which server, sign out, and who made it.

## How it is built

The web app talks to the server through PocketBase's JavaScript SDK; the phone uses its official Dart
twin, so both clients sign in, list photos and fetch files the same way, with the same rate limits and the
same two-factor rules. Everything else comes from Google's own Flutter packages, and there is no
state-management framework: a small app does not need one ([ADR 0021](../adr/0021-mobile-app-stack.md)).

Besides the usual tests against a fake server, an optional test runs the app's session against a real
Alcove server: sign in, list photos, download a thumbnail and an original. It passed against a fresh
instance.

## What went wrong

- **"Made by Closure".** The account screen showed `Closure: (String) => String` where the credit should be.
  A translation key called `madeBy` already existed, taking the author's name as a parameter, and I had
  given it new text without the parameter. Dart turned the function itself into text. A widget test caught
  it; the original key is used properly now.
- iOS cannot be built on my machine yet (it needs the full Xcode). Android builds; iOS builds will move to
  the continuous integration.

## Next

Automatic backup: the app reads the phone's photo library, uploads new pictures and videos in the
background (resumable, on Wi-Fi or while charging if you want), and skips what is already on the server.
