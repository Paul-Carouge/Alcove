# v0.17.0: Running a server for others

*2026-10-12, Paul Carouge*

Alcove is meant to be installed by one person for a household. Until now, that person had to open the
PocketBase console, find the `users` collection and type a quota in bytes to give someone an account.
This release brings everything a family server needs into the app itself.

## For the administrator

**Users**, in the account menu, lists every account with the space it uses and whether it has two-factor
turned on. **New account** asks for an email, a name and an optional quota in gigabytes, and generates a
password that is easy to read aloud (`a7Kq-9mPx-…`, no 0/O or 1/l). It is shown once, to hand over. From the
same list: change someone's quota or role, reset a forgotten password, or delete an account. Deleting asks
you to type the email address, because it removes everything that person owns.

Two rules keep a server from locking itself out: you cannot remove your own administrator role or delete
yourself here, and the last administrator always stays.

## For everyone

**Account** lets you change your name and your password. Changing the password signs you out on every
device, including this one, and you sign in again with the new one.

**Photos** can now be thrown away from where you look at them: select several and move them to the trash,
or do it from the viewer. Favorites work on a selection too. **Files** has a search box: type part of a name
to find a file or folder wherever it is.

## What went wrong

- **"Your password was changed" never showed.** After a password change, the app signs you out, and the
  page's own guard sent you to the sign-in screen before my code could add its little notice to the
  address. The notice now waits in the tab's session storage.
- **The test suite started failing at random.** Forty tests signing in and loading pages from one address
  ran into Alcove's own protection: at most 60 health checks per minute per address. The throwaway test
  server now relaxes that limit; real servers keep it.
- **The privacy test caught the map talking to OpenStreetMap.** It was right: another test had just switched
  the tiles on for the whole server. The two now run one after the other.
