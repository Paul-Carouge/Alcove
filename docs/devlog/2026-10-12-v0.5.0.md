# v0.5.0: Sharing, carefully

*2026-10-12, Paul Carouge*

**Links.** Any file or folder can be shared through a public link, with an optional expiry and
password, and revoked at any time from the new "Shared" page. Visitors need no account: they get a
clean page with a preview and a download button, or a browsable folder.

**The trade-off.** The server stores only a hash of each link token. If the database ever leaks, no
link can be rebuilt from it. The cost: a link is shown once, at creation. Lose it, create another.
Password-protected links exchange the password for a one-hour access token signed with a secret
unique to that link, so revoking the link invalidates every session at once. Folder links cannot be
used to reach anything outside the shared folder, and password attempts are rate limited.

**What went wrong.** A test uploading into a freshly opened folder failed in a way that exposed a real
race: if an upload finished while the folder's listing was still loading, the late listing overwrote
the live update and the file disappeared from view. Events received during loading are now replayed
on top of the listing.

**Also in this release.** Versions are now cut for every batch of work, with a changelog, this devlog,
and tagged releases that publish Docker images for amd64 and arm64.

**Next.** Storage quotas, authenticator-app two-factor (TOTP), and a first-run setup wizard.
