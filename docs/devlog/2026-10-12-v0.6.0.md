# v0.6.0: Knowing how full the shelf is

*2026-10-12, Paul Carouge*

**Quotas.** A self-hosted server is shared hardware: one family member's phone backup should not fill
the disk for everyone. The administrator can now give each account a quota (or leave it unlimited).
Usage includes the trash, because trashed files still take space until they are purged, and the
sidebar shows a meter that turns into a warning past 90%.

**Where it is enforced.** Twice, on purpose. When an upload starts, the server already knows its size
and refuses it immediately if it cannot fit, so nobody waits for a 4 GB video to finish uploading only
to be told no. Then, when the file is actually created, the check runs again inside the drive hook:
that is the only place every write path goes through, and it settles the case of two uploads that
each fit alone but not together.

**What went wrong.** The first version of the check always answered "internal error". The quota
error was a validation object containing a map, which Go cannot compare, so `errors.Is` never
recognised it. It is now a plain sentinel error, and the API-facing validation error is matched by its
code. The end-to-end test for the meter also caught a missing test account before any human could.
