# v0.8.0: The first five minutes

*2026-10-12, Paul Carouge*

**Why it matters.** The first five minutes decide whether someone keeps a self-hosted app. Until now,
a fresh Alcove printed a PocketBase installer link in the logs, which created an account for the
admin console only. The administrator then had to create a second account to actually use the app.

**The wizard.** The log line now points to `/setup`, and any page redirects there until setup is done.
Four short steps: check the token, create the administrator (one set of credentials for both the admin
console and the app), optionally configure email with a "send a test email" button, and a summary that
includes a real write test of the storage. Finishing signs you straight into your empty drive.

**The security question.** Between first start and setup, a server exposed to the internet is up for
grabs: whoever completes setup owns it. The wizard therefore requires the one-time token from the logs
(or preset with `ALCOVE_SETUP_TOKEN` for automated deployments), compares it in constant time, rate
limits the routes, and serializes completion: a test fires five setups at once and checks that exactly
one administrator comes out.

**What went wrong.** The Port field of the email step overflowed its column: text inputs have an
implicit minimum width, so a narrow grid column could not shrink them. And the end-to-end test needed
a server that has never been set up, so Playwright now starts a second, brand-new instance just for it.

**Phase 1 is done.** Accounts with two-factor, a drive with resumable uploads, previews, sharing,
trash and quotas, and a proper first run. Next comes phase 2: photos and videos.
