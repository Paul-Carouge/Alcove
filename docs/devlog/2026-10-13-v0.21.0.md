# v0.21.0: The phone joins in

*2026-10-13, Paul Carouge*

Until now the Android app could look at files but not add any, apart from photo backups. That was the
biggest gap left on the phone, and it closes here.

## Sending and scanning

Two new dependencies, chosen by the user: the system file picker, and Google's ML Kit document scanner.
The scanner finds the page edges, straightens them, takes as many pages as needed and hands back a single
PDF. Alcove sends it like any other file, and the server reads it by OCR, so a letter scanned in the
kitchen can be found by a word in it a minute later. The scanning itself happens on the phone; nothing goes
to Google.

The uploads reuse the tus client written for photo backups, one file at a time, with a small banner at the
bottom of Files that shows "Sending 2 of 3" and the file name, then folds into a summary.

## Managing files

Long press, or the ⋯ button, on any file or folder: rename, move, trash. Moving opens a folder picker that
refuses to enter the folder being moved, and the server refuses a cycle anyway. Trashing is immediate, with
an Undo in the snackbar, which is friendlier than a confirmation dialog for something that can be restored.
Names are checked on the phone with the same rule as the server, so "a/b" is refused before any request.

## What went wrong

- On the web, the upload panel stayed open in the bottom-right corner after every upload, covering the
  buttons below it. The last release's end-to-end test had to close it by hand, which was the hint. It
  now folds on its own once everything has arrived.
- The new floating button had no theme and showed in the default Material colours. It now uses the
  accent colour and Alcove's corner radius.
