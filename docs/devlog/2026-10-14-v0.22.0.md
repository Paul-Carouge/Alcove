# v0.22.0: Labels that stay readable

*2026-10-14, Paul Carouge*

Folders answer "where is it?", tags answer "what is it?". A lease can live in "Housing" and still be
tagged "Contracts" and "Taxes 2025". This release adds tags everywhere files appear.

## On files, not only documents

Tags could have been a documents feature. They are put on files and folders instead, so a tagged folder of
holiday receipts works as well as a tagged PDF. Each person has their own tags; a file keeps up to twenty.
Tag ids are not secret, so the server checks that every tag on a file belongs to the file's owner, rather
than trusting the relation field alone. Deleting a tag removes it from the files and keeps the files.

## Colours with rules

Nine colours, each a dark text on a light tint (and the reverse in dark mode). They live in the design
tokens like every other colour, so the web and the app share them, and the contrast test now checks all
eighteen pairs against WCAG AA. The colour picker in the web dialog shows the strong colour as a filled
dot: the tints alone were almost invisible on a white dialog.

## What went wrong

- The phone's action sheet gained a fourth line and no longer fit on a small screen: Flutter caps bottom
  sheets at about half the height. The widget tests run in a small window and caught it. Every sheet now
  scrolls.
- The mobile tag lookup rebuilt its index for every tag of every file. Harmless with three tags, wasteful
  with a hundred; it is built once per list now.
