# v0.23.0: Text you can select

*2026-10-14, Paul Carouge*

Three smaller pieces that make documents more useful once they are in Alcove.

## Searchable PDFs

A scanned page is a picture: Alcove can search it because it reads it, but a PDF reader cannot. Tesseract
can do more than read: it can lay the picture out in a PDF with the recognised words invisible on top, in
the right places. Alcove now does that on request, page by page, joins the pages with poppler's
`pdfunite` and saves `<name> (OCR).pdf` next to the original, whose text can be selected and copied in any
reader. Pages are rendered as JPEG first, which keeps a page around 50 KB instead of several megabytes.
The job runs in the background, one at a time; the web page and the app wait for it and say when the copy
is there. The new PDF is then read like any other, through its text layer this time.

## Search by tag

Typing "fact" now also finds the files tagged "Factures", between name matches and text matches.

## Uploads that survive

Sending files from the phone used to stop for good if the app was closed. The queue now keeps its own
copy of each file and saves itself with the tus upload address, so the next start resumes where it
stopped. The copies are deleted once sent.

## What went wrong

- A request asking for a searchable PDF while the server stops could have written to a closed channel and
  crashed it. The queue is now closed and filled under the same lock.
- A commit failed its checks because an end-to-end test edited by script was not formatted, and the next
  commit failed with it because the files were still staged. Small, but it is why the hooks lint before
  every commit.
