# v0.24.0: The rooms nobody visits

*2026-10-14, Paul Carouge*

A design pass over the pages that had not been looked at since they were built: albums, shared links,
the trash, user administration, account, security, sign-in and the public pages visitors see.

## Looking with real data

Empty pages always look fine. This pass started with a seeded server: three accounts, folders, photos,
documents, an album shared between two people, public links with and without a password or an expiry,
and a few items in the trash, then screenshots of every page in light, dark and on a phone. Most pages held
up. Three things did not.

- **The trash on a phone** squeezed names into a narrow column next to a size column, so "Ancien projet"
  broke over two lines. Size and date now sit under the name, which keeps the full width.
- **Shared links on a phone** simply lost their expiry: the column was hidden for space and nothing replaced
  it. It now appears under the name ("Expires 21 Oct.").
- **A shared folder of photos** showed a list of identical image icons to visitors. Album links already
  served thumbnails; folder links now do too, from the same generated JPEGs (no metadata in them).

And one missing feature: there was no way to empty the trash except item by item.

## What went wrong

- The seed script was refused twice by the server, rightly: once for an album cover that was not in the
  album, once for reusing accounts from a half-finished run. Data has to be seeded in the order the rules
  expect, like a person would create it.
- The screenshot server used the same port as the end-to-end tests, which then refused to start. The tests
  were right to refuse: they never reuse a server they did not start.
