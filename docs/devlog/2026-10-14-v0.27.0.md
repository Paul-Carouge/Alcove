# v0.27.0: One search field

*2026-10-14, Paul Carouge*

The last of four releases asked for together: photo comforts (v0.25), robustness and self-hosting (v0.26),
and now design.

## Where the eye goes

Screenshots of every main page, on a server filled with realistic data, showed a clean but flat app: a
top bar with nothing in it but an avatar, a sidebar listing six links, grey icons for every kind of file,
and album covers the size of a stamp.

- **Search moved to the top bar**, on every page, with the shortcut everyone expects (`⌘K` or `Ctrl+K`, or
  `/`). The Files and Documents pages had their own search boxes doing the same thing; they are gone, which
  also removed a row of clutter on phones.
- **The sidebar has two sections**, Library (files, photos, albums, documents) and Sharing (shared links,
  trash).
- **File icons are tinted by type**, with the tag colours already checked for contrast: folders in the
  accent colour, PDFs red, images green, videos pink, music violet. The app already did this; the web now
  matches.
- **Album covers are larger** and lift slightly on hover.
- **On phones**, file names no longer break mid-word next to a size column: size and date go under the
  name. Documents put their buttons on a line of their own, so titles are readable.

## What went wrong

- The size and date line under file names did not appear on phones: the rule hiding it on wide screens came
  after the rule showing it on narrow ones. In CSS, order wins ties.
- Taking the screenshots twice in a row locked the test account out for a minute: the sign-in rate limit,
  doing its job.
