# v0.32.3: Saves in order

*2026-10-17, Paul Carouge*

The upload-queue test failed once more on the 0.32.2 release, this time finding temporary files still
being written when it finished. Behind it was another real issue in yesterday's fix: each save used its
own temporary file, so two overlapping saves could rename in the wrong order and leave the older queue on
disk. Saves now run one after another, each writing the queue as it is at its turn, through a single
temporary file, and the tests wait for pending saves before looking at the disk.
